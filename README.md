# English Path

**Сайт:** <https://bogdanzhf.github.io/english-path/>

Персональный репетитор английского для русскоговорящих — от **A1 до C2**. Интерфейс на двух языках
(русский / английский, переключатель в шапке). Списки слов юнитов соответствуют серии
*4000 Essential English Words* (книги 1–6 = уровни A1–C2); определения, примеры, тексты,
грамматика, диалоги и упражнения написаны заново, материалы самих книг в проект не входят.

## Что внутри

- **6 уровней × 30 юнитов = 3600 слов.** У каждого слова — британская и американская транскрипция,
  озвучка нейроголосами в двух акцентах, перевод, определение, пример с переводом, заметки; у ~780 слов
  есть 3D-картинка.
- **180 текстов для чтения** (по одному на юнит) с переводом, озвучкой и вопросами.
- **86 тем грамматики** с таблицами и правилами на двух языках и упражнениями 11 типов: выбор,
  ввод, текст с пропусками и выпадающими списками, «найди ошибку», собрать предложение, пары,
  «лишнее», верно/неверно, восстановить диалог, аудирование, говорение.
- **Обзор времён** и таблица **неправильных глаголов**.
- **36 диалогов** по ролям с полезными фразами — для аудирования и говорения (распознавание речи
  через микрофон).
- **Личный словарь** с интервальным повторением (упрощённый SM-2) и несколькими режимами
  тренировки; можно добавлять свои слова.
- **Тесты**: по юниту, по уровню, свои — и **адаптивный тест на уровень** (108 вопросов A1–C2).
  Тест только предлагает уровень: что изучать, вы выбираете сами.
- **Игры**: кроссворд, «Найди слова» и другие.
- Светлая и тёмная темы, звуки правильного и неправильного ответа, адаптация под **iPhone и iPad**
  (нижняя панель, можно добавить на экран «Домой»).

## Два режима работы

| | Серверный | Статический (GitHub Pages) |
|---|---|---|
| Запуск | FastAPI + SQLite | любые статические файлы |
| Вход | логин и пароль | локальный профиль без пароля |
| Где прогресс | в базе на сервере | в браузере; можно выгрузить в файл и загрузить на другом устройстве |

## Запуск (серверный режим)

Нужны Python 3.11+, Poetry и Node.js 22+.

```bash
poetry install
cd frontend && npm install && npm run build && cd ..
poetry run uvicorn app.main:app --app-dir backend --port 8765
```

Откройте <http://localhost:8765>. Для iPad/iPhone в домашней сети добавьте `--host 0.0.0.0`
и откройте `http://<IP-компьютера>:8765`.

| Переменная | Значение |
|---|---|
| `ENGLISH_PATH_DB` | адрес базы (по умолчанию `sqlite:///data/english_path.db`) |
| `ENGLISH_PATH_HTTPS` | `1` — Secure-cookie и HSTS (включайте только при HTTPS) |
| `ENGLISH_PATH_SESSION_DAYS` | срок сессии в днях (30) |
| `ENGLISH_PATH_ALLOW_REGISTRATION` | `0` — закрыть регистрацию |

## Разработка

```bash
poetry run uvicorn app.main:app --app-dir backend --port 8765 --reload   # API
cd frontend && npm run dev                                             # http://localhost:5173
```

Статическая версия: `npm run build:static` (результат — `frontend/dist-static`).

### Контент

Весь учебный контент — в `backend/content` (YAML, формат описан в `backend/content/README.md`).
После изменений:

```bash
cd backend && python -m app.export      # проверка и выгрузка в frontend/public/data
python tools/build_audio.py --workers 10 # озвучка новых фраз (edge-tts)
python tools/build_images.py             # картинки (Microsoft Fluent Emoji 3D)
```

`app.export` строго проверяет контент: в каждом примере отмечено слово, у выпадающих списков
ровно один верный вариант, у «найди ошибку» ровно одна ошибка и т. д.

### Тесты

```bash
poetry run pytest                          # API, безопасность, контент (60 тестов)
cd frontend && npm test                    # логика упражнений, SRS, игры, проверка всего контента
npx playwright install chromium webkit     # один раз
npm run e2e                                # интерфейс: компьютер, iPhone и версия с сервером
```

## Безопасность (серверный режим)

Пароли — scrypt с солью и проверкой по списку утёкших/слабых; сессия в HttpOnly-cookie
`SameSite=Strict`; защита от CSRF (свой заголовок + проверка Origin); ограничение попыток входа;
строгие заголовки (CSP, X-Frame-Options, nosniff, Permissions-Policy). Данные пользователей
изолированы друг от друга.

## Публикация

Каждый push в `main` запускает GitHub Actions (`.github/workflows/pages.yml`): тесты бэкенда и
фронтенда, сборка статической версии и публикация на GitHub Pages.

## Источники и лицензии

- Списки слов — по программе *4000 Essential English Words* (Compass Publishing); тексты и упражнения
  написаны заново.
- Озвучка — нейроголоса Microsoft (edge-tts), заранее сгенерированные mp3; запасной вариант — голос
  устройства (Web Speech API).
- Иллюстрации — [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) (MIT).
