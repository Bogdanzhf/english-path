# English Path 2.0 — план переработки

Работа ведётся в ветке `v2`. На `main` и GitHub Pages — только после проверки и разрешения.

## Решения

- Курс A1–C2, словарь **~8000–9000 слов**: ~5000 базовых (A1–C1) + академическая лексика (AWL/NAWL)
  + тематическая лексика IELTS и C2. Текущий результат пользователя — A2→B1, курс строится от азов.
- **Юниты по темам** внутри уровня: уровень → тема → уроки по 15–25 слов. Старые 30 юнитов × 6 книг не сохраняются;
  нынешние 3600 слов перераспределяются по уровням и темам.
- **Прогресс не переносится** — v2 с чистого листа.
- **Многозначные слова**: основное значение — на своём уровне, важные доп. значения и устойчивые выражения —
  отдельными карточками на своих уровнях (run «бегать» A1, run «управлять» B1).
- **Аудио пережимается** (моно, ~48–64 кбит/с) — разборчивость речи сохраняется, объём ~вдвое меньше.
- **Раздел IELTS** (Writing Task 1/2, Speaking, типы Reading) — после v2.
- **Дизайн**: доступность (контраст WCAG AA, крупные элементы на телефоне, размер шрифта), 3 палитры на выбор.

## Источники

| Для чего | Источник | Как используется |
|---|---|---|
| Уровни A1–C1 | Oxford 3000 / 5000 (уровень по части речи) | главный ориентир уровня |
| Уровни A1–B2, проверка | CEFR-J Wordlist (TUFS) | сверка, темы |
| Уровни C1–C2 | Octanove C1/C2 profiles (CC BY-SA), частотность | C1/C2, спорные слова |
| Значения по уровням | English Vocabulary Profile (Cambridge) | уровни значений многозначных слов |
| Академическая лексика | AWL (570 семейств), NAWL | IELTS Reading/Writing, B2–C1 |
| Темы IELTS | IELTS Vocabulary Booster (~520 терминов, 9 тем), темы экзамена | тематические уроки B2–C2 |
| Грамматика: уровни | English Grammar Profile, British Council/EAQUALS Core Inventory | уровень каждой темы |
| Грамматика: полнота | English Grammar in Use (Murphy, 130 разделов, .chm) | перечень тем, недостающие темы |
| Стратегия IELTS | Hacking TOEFL & IELTS in 90 days | будущий раздел IELTS |

Списки используются как справка для уровней; сами списки не публикуются. Переводы, определения, примеры,
тексты и упражнения пишутся заново.

## Этапы и точки проверки

0. **Подготовка** — ветка `v2`; локальный запуск на компьютере и iPhone (домашняя сеть); новая модель данных
   (уровень → тема → урок; значения слова; стабильные id).
1. **Общий список слов** — сведение источников, дедупликация, уровень + часть речи + тема + источник уровня.
   ✅ *Проверка: таблица Excel до наполнения контентом.*
2. **Темы и уроки** — ~12–16 тем на уровень (к B2–C2 — темы IELTS), уроки по 15–25 слов.
   ✅ *Проверка: список тем и уроков.*
3. **Словарь** — транскрипция UK/US, перевод, определение, пример + перевод, доп. значения; партиями по уровням,
   с автопроверкой (как сейчас). ✅ *Проверка: образец A1, затем остальные уровни.*
4. **Озвучка и картинки** — edge-tts для слов и примеров, пережатие, Fluent-картинки к конкретным словам.
   Оценка размера сайта ~450 МБ (лимит Pages — 1 ГБ).
5. **Грамматика** — сверка 86 тем с EGP/Core Inventory, перенос уровней, ~25 новых тем по Murphy (итого ~110),
   упражнения и «Письмо» к новым. ✅ *Проверка: список тем с уровнями.*
6. **Тексты, диалоги, тесты** — тексты по темам (новые + прежние 180, переразмеченные по уровню), диалоги,
   тесты уровней, новый тест на уровень.
7. **Дизайн v2** — 3 палитры (светлая/тёмная) на странице предпросмотра, контраст, размер шрифта.
   ✅ *Проверка: выбор палитры.*
8. **Проверка** — автотесты, обход всех страниц, iPhone/iPad. ✅ *Локальная проверка пользователем →
   слияние с `main` → публикация.*

## Найденные проблемы v1 (подтверждено проверкой)

- Нет базовых слов: tree, house, car, big, small, happy, mother, father, sister, teacher, money, buy, phone,
  computer, email, summer, winter, hot, cold, good, new… (37 из 64 проверенных).
- Неверные уровни: delete, fast — C2; job — B2; на A1 — attribute, bilingual, ritual, vague, scholarship,
  injustice, overwhelm, perception.
- Грамматика: нет ~25 тем Murphy (So am I / Neither am I, prefer / would rather, had better, see someone do,
  uncountable nouns, reflexive pronouns, all/every/whole, -ing/-ed adjectives, adjective order, still/yet/any more,
  quite/rather, as/like, for/during/while, by/until, noun/adjective/verb + preposition …).
